# IMPORTANTE

Este proyecto NO es un chatbot.

Este proyecto NO es un asistente conversacional.

Este proyecto NO consiste en integrar modelos LLM.

El proyecto DHP pretende construir un SISTEMA OPERATIVO EMPRESARIAL basado en IA.

La IA será únicamente un componente del sistema.

Nunca será el sistema.

---

# FILOSOFÍA

El objetivo consiste en desacoplar completamente la lógica empresarial del modelo de inteligencia artificial utilizado.

El Kernel DHP nunca deberá depender de:

- OpenAI

- Claude

- Gemini

- Hermes

- DeepSeek

- Copilot

- ningún modelo concreto

Todos ellos serán simplemente consumidores del Kernel.

---

# OBJETIVO FINAL

Construir un empleado digital capaz de gestionar completamente la empresa DHP mediante lenguaje natural.

Entre otras funciones deberá controlar:

- Prestashop

- PostgreSQL

- Oracle Cloud

- Docker

- GitHub

- Listmonk

- documentación

- campañas

- clientes

- productos

- descuentos

- proveedores

- inventario

- futuras aplicaciones

OBJETIVO DE ESTE DOCUMENTO
==============================================================================

Este documento define la visión completa del proyecto DHP.

No describe la implementación.

No describe el código.

Describe QUÉ se pretende construir y POR QUÉ.

Debe permanecer prácticamente invariable durante toda la vida del proyecto.

==============================================================================
¿QUÉ ES DHP?
==============================================================================

DHP no es un chatbot.

DHP no es un asistente basado en IA.

DHP no es una automatización.

DHP pretende convertirse en un Sistema Operativo Empresarial Inteligente.

La inteligencia artificial será únicamente uno de sus componentes.

Nunca será el núcleo.

El núcleo será siempre el Kernel DHP.

==============================================================================
VISIÓN A LARGO PLAZO
==============================================================================

El objetivo final consiste en construir un empleado digital capaz de gestionar
la empresa mediante lenguaje natural.

No debe limitarse a responder preguntas.

Debe ser capaz de:

- pensar

- planificar

- recordar

- investigar

- aprender

- ejecutar acciones

- administrar sistemas

- desarrollar software

- desplegar aplicaciones

- comunicarse con clientes

- controlar servicios

- documentar automáticamente

- detectar errores

- proponer mejoras

Todo ello sin depender de un proveedor concreto de inteligencia artificial.

==============================================================================
FILOSOFÍA DEL PROYECTO
==============================================================================

Todo el conocimiento empresarial debe residir en el Kernel DHP.

Nunca en el modelo LLM.

El modelo únicamente interpreta lenguaje natural.

Toda la lógica empresarial debe permanecer independiente.

Esto permitirá sustituir cualquier IA sin modificar el resto del sistema.

==============================================================================
PRINCIPIOS FUNDAMENTALES
==============================================================================

PRINCIPIO 1

Desacoplamiento absoluto.

El Kernel nunca dependerá de:

- OpenAI

- Claude

- Gemini

- Hermes

- DeepSeek

- Copilot

- cualquier otro modelo.

Todos ellos serán adaptadores.

Nunca el núcleo.

------------------------------------------------------------------------------

PRINCIPIO 2

Todo servicio debe ser intercambiable.

Prestashop.

PostgreSQL.

Listmonk.

Docker.

GitHub.

Oracle.

Todos deberán poder sustituirse sin reescribir el Kernel.

------------------------------------------------------------------------------

PRINCIPIO 3

Toda decisión importante deberá quedar documentada.

Nunca volver a debatir problemas ya resueltos.

Nunca repetir investigaciones cerradas.

------------------------------------------------------------------------------

PRINCIPIO 4

Toda automatización deberá poder ejecutarse mediante lenguaje natural.

Ejemplos:

"Crea un producto."

"Haz una copia de seguridad."

"Actualiza el servidor."

"Envía una campaña."

"Busca el cliente."

"Crea una rama."

"Haz commit."

"Haz deploy."

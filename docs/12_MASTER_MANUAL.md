OBJETIVO
==============================================================================

Este documento constituye la especificación oficial del proyecto DHP.

No es un resumen.

No es una guía rápida.

No es un documento de arquitectura aislado.

Es el manual maestro que describirá absolutamente todos los aspectos técnicos,
funcionales y arquitectónicos del sistema.

El objetivo es que cualquier desarrollador o cualquier sistema de inteligencia
artificial pueda comprender el proyecto completo sin necesidad de reconstruir
el contexto a partir de conversaciones anteriores.
